# ADR 0003 — Vue 3 recruiter console

## Status

Accepted.

## Context

Portfolio frontend families: A=React, B=Angular. C must be Vue.

## Decision

Vue **3.5.x**, TypeScript strict, Pinia 4, Vue Router 5, SCSS, Vite 8. Firebase Hosting. Integration Boundary Graph in Vue (SVG).

## Why Vue?

Intentional framework differentiation. Vite SPA is enough; Nuxt/Next would add SSR hosting cost without a recruiter-SEO need.

## Consequences

Phase 2 scaffold. No shared UI kit with A/B.
